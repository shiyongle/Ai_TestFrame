# 卷心菜开发文档

## 项目概述

卷心菜是一个开源的前后端分离的智能化测试平台，支持多种协议的接口测试，包括HTTP、TCP、MQ等。系统采用现代化的技术栈，提供直观的用户界面和强大的测试功能。

## 技术架构

### 后端技术栈
- **框架**: FastAPI (Python)
- **数据库**: MySQL 5.7+ / 8.0+
- **ORM**: SQLAlchemy
- **数据库驱动**: PyMySQL
- **配置管理**: python-dotenv
- **异步支持**: asyncio, aiohttp
- **任务队列**: Celery (预留)

### 前端技术栈
- **框架**: React 18 + TypeScript
- **UI库**: Ant Design
- **路由**: React Router
- **HTTP客户端**: Axios
- **状态管理**: React Hooks

## 数据库设计

### 数据库配置
系统使用MySQL作为主数据库，支持通过环境变量配置连接参数：

```bash
# .env 文件配置示例
MYSQL_USER=root
MYSQL_PASSWORD=password
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DATABASE=test_system

# 连接池配置
DB_POOL_SIZE=10
DB_MAX_OVERFLOW=20
DB_POOL_TIMEOUT=30
```

### 主要数据表

1. **projects** - 项目表
   - id, name, description, created_at, updated_at
   - 索引：idx_projects_name

2. **testcases** - 测试用例表
   - id, name, description, protocol, config, project_id
   - 外键：project_id -> projects.id
   - 索引：idx_testcases_project, idx_testcases_protocol

3. **test_results** - 测试结果表
   - id, testcase_id, status, response_data, execution_time, error_message, executed_at
   - 外键：testcase_id -> testcases.id
   - 索引：idx_test_results_testcase, idx_test_results_status, idx_test_results_executed_at

4. **versions** - 版本管理表
   - id, version_number, description, changes, created_at, created_by
   - 索引：idx_versions_number, idx_versions_created_at

5. **test_reports** - 测试报告表
   - id, version_id, project_id, total_tests, passed_tests, failed_tests, error_tests, summary, created_at
   - 外键：version_id -> versions.id, project_id -> projects.id
   - 索引：idx_test_reports_version, idx_test_reports_project, idx_test_reports_created_at

6. **test_data** - 测试数据表
   - id, name, data_type, content, project_id, created_at, updated_at
   - 外键：project_id -> projects.id
   - 索引：idx_test_data_project, idx_test_data_type

### 数据库初始化
使用提供的SQL脚本初始化数据库：
```bash
mysql -u root -p < backend/init_mysql.sql
```

## API接口文档

### 项目管理
- `GET /api/projects` - 获取项目列表
- `POST /api/projects` - 创建项目
- `GET /api/projects/{id}` - 获取项目详情

### 测试用例
- `GET /api/projects/{project_id}/testcases` - 获取测试用例
- `POST /api/projects/{project_id}/testcases` - 创建测试用例

### 测试执行
- `POST /api/test/http` - 执行HTTP测试
- `POST /api/test/tcp` - 执行TCP测试
- `POST /api/test/mq` - 执行MQ测试
- `POST /api/test/batch` - 执行批量测试

### 版本管理
- `GET /api/versions` - 获取版本列表
- `POST /api/versions` - 创建版本记录

## 快速开始

### 环境要求
- Python 3.8+
- Node.js 16+
- MySQL 5.7+ / 8.0+
- Git

### 启动方式

#### 方式一：使用启动脚本 (推荐)
```bash
# Windows
start.bat
```

#### 方式二：手动启动

**1. 数据库准备**
```bash
# 创建MySQL数据库
mysql -u root -p
CREATE DATABASE test_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 执行初始化脚本
mysql -u root -p test_system < backend/init_mysql.sql

# 配置环境变量
cd backend
cp .env .env
# 编辑 .env 文件，修改数据库连接信息
```

**2. 后端启动**
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

**3. 前端启动**
```bash
cd frontend
npm install
npm start
```

### 访问地址
- 前端界面: http://localhost:3000
- 后端API: http://localhost:8000
- API文档: http://localhost:8000/docs
